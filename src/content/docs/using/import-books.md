---
title: Import books
description: Find books in a source, match them to Open Library, and confirm what to add to your library.
---

Once a source is set up, you find books in it from the Import screen.

1. Run a discovery pass against the source. Alexandryn finds candidate files and
   matches them against Open Library metadata where it can.
2. Review each candidate. If Open Library guessed wrong or found nothing, correct the
   match.
3. Confirm the ones you want.

Nothing is added to your library without your confirmation.

Alexandryn does not copy your book files into its own storage. Your library holds the
record of what you have and where it comes from, and the files stay in the source.
