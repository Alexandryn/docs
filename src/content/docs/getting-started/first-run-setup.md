---
title: First-run setup
description: Create the administrator account the first time you open Alexandryn.
---

The first time you open Alexandryn, on the desktop or on a server, it shows a setup
screen instead of a login screen, because no account exists yet.

1. Enter a username and an email address.
2. Choose a password of 8 to 128 characters.
3. Create the account.

This account is an administrator. It can create other accounts and configure sources.

Once it exists, the setup screen never appears again. Every later visit shows the
ordinary login screen.
